# 荣耀电视轻量桌面（HonorTVLauncher）

一个面向荣耀智慧屏 X1 等低内存电视设备的极简桌面。

## 功能

- 只显示电视端可启动的应用
- 遥控器方向键移动焦点
- 确认键启动应用
- 首页显示可用内存和当前时间
- 不联网、无广告、无后台常驻服务
- 不修改系统分区、不禁用系统应用

## 环境要求

- JDK 17
- Android SDK Build-Tools 28.0.3
- Android SDK Platform android-28
- Android Studio Dolphin 或更新版本

## 构建步骤

### 方式一：Android Studio（推荐）

1. 打开 Android Studio。
2. 选择 `Open` 并选中本工程目录。
3. 首次打开会提示下载 Gradle 7.5，允许下载。
4. 等待 `Sync Project with Gradle Files` 完成。
5. 点击菜单 `Build - Make Project`。
6. 构建成功后，APK 位于：

   ```
   app/build/outputs/apk/debug/app-debug.apk
   ```

### 方式二：命令行

确认已配置 `JAVA_HOME` 和 `ANDROID_HOME`，然后在工程根目录执行：

```bat
gradlew.bat assembleDebug
```

Linux/macOS：

```bash
./gradlew assembleDebug
```

## 安装到荣耀智慧屏 X1

**重要：** 荣耀智慧屏 X1 未开放 ADB 网络调试，不要尝试以下操作：

- 扫描电视端口
- 强行停止原厂桌面
- 刷机或替换系统镜像
- 通过未知工具启用 ADB

### 推荐安装流程

1. 在电脑上完成构建，得到 `app-debug.apk`。
2. 将 APK 复制到 U 盘根目录。
3. 将 U 盘插入电视。
4. 使用电视自带的“文件管理”或“媒体中心”打开 U 盘。
5. 点击 APK 文件，按提示完成安装。
6. 安装后进入：

   ```
   设置 - 应用 - 默认应用 - 主屏幕应用
   ```

7. 选择“荣耀电视轻量桌面”。
8. 按主页键返回桌面，确认是否切换成功。

## 如果系统没有主屏幕应用选项

说明这台电视的桌面组件由系统锁定，无法替换。

此时请直接：

```
设置 - 应用 - 荣耀电视轻量桌面 - 卸载
```

**不要尝试禁用原厂桌面。** 如果原厂桌面被禁用而新桌面无法启动，电视可能黑屏或无法恢复。

## 恢复原厂桌面

任选其一：

- 卸载“荣耀电视轻量桌面”；
- 系统设置中将默认桌面改回原厂桌面；
- 恢复出厂设置。

## 关于降低内存占用

本桌面本身不杀进程、不卸载应用、不接管系统服务。它只是提供一个比原厂桌面更轻的入口。

真正影响内存的因素通常是：

- 多个视频应用常驻后台
- 系统推荐与内容服务
- 语音唤醒服务
- 安装应用过多

建议结合系统设置关闭智慧语音、减少自启动应用，并定期重启电视。
